# College Notice Board

## Project Description

College Notice Board is a simple Java web-based mini project developed to manage college notices digitally.

The project allows users to add, view, update and delete college notices.

## Technologies Used

* Java
* JSP
* Servlet
* JDBC
* PostgreSQL
* HTML
* CSS
* Apache Tomcat

## Features

* Add new notice
* View all notices
* Edit and update notices
* Delete notices
* Store notices in PostgreSQL database

## CRUD Operations

* **Create** – Add a new notice
* **Read** – View notices
* **Update** – Edit an existing notice
* **Delete** – Delete a notice

## Project Purpose

The main purpose of this project is to provide a simple digital system for managing college notices.

## How to Run

1. Start PostgreSQL.
2. Start Apache Tomcat.
3. Deploy the project in the Tomcat `webapps` folder.
4. Open the project in a browser.
